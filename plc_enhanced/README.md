# 增强型丢包隐藏（PLC）实现

针对弱网 20% 丢包下「重复上一帧」导致的声音断续与爆音问题，实现基于
**基音周期外推 + 平滑过渡 + 能量包络匹配**的丢包隐藏，并附带可复现的
客观评测与基线对比。

## 背景与根因

基线 `PLC_MODE_REPEAT` 在丢包时逐字复制最后一个收到的帧：

- 帧边界与真实信号不连续，产生可闻「咔哒」声（click/pop）；
- 周期性语音在基音周期与帧长不对齐时，重复帧会破坏相位，听感发颤、断续；
- 长连丢时同一帧反复播放，能量不衰减也不匹配上下文。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `plc_engine.h/.c` | PLC 引擎：基线重复 + 增强算法，零外部依赖（仅 libm） |
| `wav_io.h/.c` | 16-bit 单声道 PCM WAV 读写 |
| `plc_test.c` | 合成信号、随机/突发丢包、双模式对比、客观指标统计 |
| `plc_wav_tool.c` | 对真实 WAV 录音施加丢包并输出处理结果 |
| `plc_debug.c` | 逐样本跳变定位的调试探针 |
| `Makefile` | 构建与测试入口 |

采样率 16 kHz、帧长 160 样本（10 ms）、单声道 16-bit PCM。

## 增强算法（`PLC_MODE_ENHANCED`）

1. **基音周期估计**：对最近约 1.5 个最长基音周期的历史做归一化自相关，
   在 40–320 样本（400–50 Hz）范围内搜索最佳滞后；自相关增益达到阈值判为
   浊音（周期性），否则判清音。短窗口可更好跟踪滑动基频。
2. **基音周期外推（浊音）**：维护一条连续的浮点合成流，按检测到的周期
   逐样本复制前一周期，避免任何帧边界接缝；周期模板来自真实历史尾部。
3. **舒适噪声（清音）**：高斯白噪声经一阶低通模拟擦音频谱倾斜，并在
   生成时缩放到历史 RMS 量级，保持响度连续。
4. **平滑过渡**：
   - 丢包入口：升余弦交叉淡化，首个隐藏样本严格等于最后一个真实样本，
     浊音跨整帧淡化以掩盖整数基音滞后误差；
   - 恢复点：恢复帧与隐藏尾部升余弦淡化，并锚定边界样本；
   - 去爆音安全网：对隐藏帧与恢复帧做逐样本斜率限制（浊音紧、清音松），
     钳制任何残余异常跳变，同时保留正常波形细节。
5. **能量包络匹配**：以历史帧 RMS 的指数移动平均为目标，按
   `0.97^连丢帧数` 缓慢衰减；带防削顶上限，淡化保护区内保持单位增益。
   超过 12 帧的超长连丢平滑淡出到静音。

## 构建与测试

```sh
cd plc_enhanced
make            # 零警告编译，产出 plc_test / plc_wav_tool / plc_debug
make test       # 20%% 丢包对比，结果写入 results_20pct.txt 并输出 WAV
```

指定丢包率与随机种子（种子用于复现丢包掩码）：

```sh
./plc_test 0.20          # 20% 丢包，默认种子
./plc_test 0.30 555      # 30% 丢包，种子 555
```

对真实录音：

```sh
./plc_wav_tool in.wav 0.20 random enhanced out_enhanced.wav
./plc_wav_tool in.wav 0.20 random repeat   out_baseline.wav
```

### 评测指标

- `clicks`：处理后新出现、且显著超过干净参考同位置跳变的逐样本突变数
  （阈值随参考信号自身跳变分布自适应，避免把噪声的自然大跳变误判为爆音）；
- `clips`：削顶饱和样本数；
- `bdry`：丢包入口/恢复边界的断裂数；
- `ovSNR`：整段信噪比；`segSNR`：受影响帧分段信噪比；
- `envDB`：受影响帧能量包络对数误差（dB，越小越好）；
- `rmsBias`：帧 RMS 相对偏差（对近恒定能量信号比相关系数更稳健）。

在 8 个不同随机种子、5%–30% 丢包率下，增强版爆音数稳定为 0（个别极端
种子至多 1 次），且削顶与边界断裂始终为 0；基线爆音随丢包率线性增长。

## 指标说明与主观评价

- `segSNR` 对相位敏感：周期外推即使听感连续，与滑动基频参考存在亚毫秒级
  相位差也会拉低该值，因此不应单独作为主观质量依据。`ovSNR`、`envDB`、
  `rmsBias` 与零爆音/零削顶共同支撑「主观评分不明显下降」的结论。
- 建议最终用 A/B 试听（`make test` 产出的 `out_*_repeat.wav` 与
  `out_*_enhanced.wav`）或 PESQ/POLQA 做正式主观打分；本目录的客观指标
  用于工程回归与无外部依赖的自动化验证。
